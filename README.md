## 〔 01 〕 About Me

I'm **Abdul Rehman**, a Data Science student and aspiring **Data Scientist / Machine Learning Engineer** from Pakistan 🇵🇰.

My interest in data science started with curiosity about how data can be used to explain and predict real-world outcomes. Since then, I've been building skills across Python, statistics, data analysis, visualization, and Machine Learning.

I focus on building practical, end-to-end projects — from data cleaning and exploratory analysis to trained models and deployed applications — rather than isolated exercises.

Currently focused on:

* 🤖 Machine Learning

* 📈 Data Visualization

> **Learn → Build → Evaluate → Improve → Repeat.**
